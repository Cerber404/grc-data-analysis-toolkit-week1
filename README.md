# GRC Data Analysis Toolkit — Week 1

Course: **Cybersecurity Policy & Risk Management**

Case company: **MedCore Regional Hospital**

## Assignment

This repository contains the Week 1 Python practical assignment.

### Part 1 — Organizational Profile Analyzer

The program:

- identifies applicable regulatory frameworks from an organization profile;
- scores Governance, Risk, and Compliance maturity from 1 to 5;
- generates a formatted GRC readiness report.

For MedCore Regional Hospital, the main frameworks identified by the assignment logic are:

- HIPAA Security Rule
- PCI-DSS v4.0
- NIST Cybersecurity Framework 2.0

### Part 2 — CIA Triad Impact Classifier

The program classifies security events by:

- Confidentiality
- Integrity
- Availability

It also reports the primary CIA impact and a simple severity value.

## Run

Python 3.10+ is recommended.

```bash
python grc_toolkit.py
```

or:

```bash
python3 grc_toolkit.py
```
